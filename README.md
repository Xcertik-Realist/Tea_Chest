
# Tea Chest - Decentralized Encrypted Storage

![Tea Chest Logo](https://via.placeholder.com/150x50.png?text=Tea+Chest)

Tea Chest is a decentralized storage solution built on the Tea Protocol, providing end-to-end encrypted, distributed file storage with real-time collaboration capabilities.

## Features

- 🔒 **End-to-End Encryption**: Files encrypted before leaving your device
- 🌐 **Decentralized Storage**: Files distributed across IPFS network
- 👥 **Real-time Collaboration**: Multiple users can edit simultaneously
- ⏳ **Version History**: Track and revert to previous file versions
- 🔐 **Zero-Knowledge Proof**: We never access your files or keys
- ⚡ **Tea Protocol Integration**: Fast access via decentralized computation

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Tea Protocol wallet (for crypto payments)

### Installation
1. Visit [https://teachest.app](https://teachest.app)
2. Create an account
3. Download desktop/mobile apps (optional)

## Usage

```bash
# CLI commands (coming soon)
teachest login
teachest upload ./myfile.txt
teachest share myfile.txt --user=friend@example.com
```

## Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Alpine.js
- **Backend**: Tea Protocol, IPFS, WebRTC
- **Encryption**: AES-256, Zero-Knowledge Proofs
- **Blockchain**: Tea Protocol, Ethereum
