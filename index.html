How Base Drive works

A technical breakdown of our decentralized storage solution on Base

Client-Side Encryption

Files are encrypted on your device before upload using AES-256.

IPFS Storage

Encrypted chunks are distributed across the InterPlanetary File System.

Base Settlement

Content addresses, access control, and payments settle on Base via ERC-20.

Collaboration

End-to-end encrypted real-time collaboration using WebRTC and CRDTs.

FAQ

Frequently asked questions

How is Base Drive different from Google Drive or Dropbox?

Base Drive is decentralized. Files are encrypted client-side and stored on IPFS. Access control and payments settle on Base. No single company holds your data or keys.

What is the BDRIVE token?

BDRIVE is an ERC-20 utility token deployed on Base. It is used to pay for storage and pinning, incentivize nodes, and participate in protocol decisions. Paying with BDRIVE unlocks a discount.

What happens if I lose my encryption key?

Your key is generated and stored only on your devices. If you lose all copies there is no recovery path — by design. Base Drive provides tools to safely export and back up your key.

How does real-time collaboration work with encryption?

Collaborators sync over end-to-end encrypted WebRTC connections. Changes are encrypted with the file key. CRDTs keep state consistent even when peers are temporarily offline.

How is file availability ensured on IPFS?

Storage payments in BDRIVE (or ETH/USDC) incentivize nodes to pin your content. Higher demand and longer retention increase the incentive for redundancy across the network.

Can I use Base Drive for my business?

Yes. Enterprise plans include team management, advanced sharing controls, audit logs, and SAML SSO. Contact sales for custom requirements.
