Features

Storage built for Base

Secure, decentralized, and collaborative file storage powered by Base and IPFS.

End-to-End Encryption

All files are encrypted before leaving your device. Only you and those you share with can access the contents.

Decentralized Storage

Files are distributed across the IPFS network, ensuring redundancy and eliminating single points of failure.

Real-time Collaboration

Multiple people can edit documents simultaneously with end-to-end encrypted collaboration.

Version History

Every change is tracked and stored. Revert to any previous version of your files at any time.

Zero-Knowledge

We never have access to your files or encryption keys. Your privacy is mathematically guaranteed.

Native to Base

Built on Base for low-cost transactions, fast finality, and seamless ERC-20 payments with BDRIVE.

Technology

How Base Drive works

A technical breakdown of our decentralized storage solution on Base

Client-Side Encryption

Files are encrypted on your device before upload using AES-256.

IPFS Storage

Encrypted chunks are distributed across the InterPlanetary File System.

Base Settlement

Content addresses, access control, and payments settle on Base via ERC-20.

Collaboration

End-to-end encrypted real-time collaboration using WebRTC and CRDTs.

Decentralized by design

Base Drive combines IPFS for content addressing with Base for low-cost settlement, access control, and the BDRIVE ERC-20 utility token.

  • No single point of failure — files distributed across IPFS nodes

  • Mathematically private — zero-knowledge architecture

  • Pay on Base — BDRIVE ERC-20, ETH, or USDC

  • Open source — client code is auditable

BDRIVE Token

The Base Drive ERC-20

BDRIVE is the native utility token on Base used for storage payments, pinning incentives, and protocol governance.

Utility

Pay for storage, bandwidth, and long-term pinning with BDRIVE. Holders receive preferential rates.

Incentives

Nodes that pin content earn BDRIVE. Storage demand directly drives token utility on Base.

Network

Deployed as a standard ERC-20 on Base. Low fees, fast confirmation, fully onchain.
